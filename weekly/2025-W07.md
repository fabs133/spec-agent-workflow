## 🚧 Probleme & Lösungen

### Problem 1: Kalenderwochen-Berechnung über Jahreswechsel
- **Impact**: Mittel
- **Ursache**: ISO 8601 definiert Woche 1 als die mit dem 4. Januar, was zu Edge Cases führt
- **Lösung**: Python's `isocalendar()` verwendet + explizite Jahresübergang-Logik
- **Code**: 
  ```python
  jan4 = date(year, 1, 4)
  week_start = jan4 - timedelta(days=jan4.weekday()) + timedelta(weeks=week - 1)
  ```
- **Lessons Learned**: Date-Handling nie selbst implementieren, Standard-Libraries nutzen

### Problem 2: Repository-Struktur Anforderungen vs. Python Best Practices
- **Impact**: Niedrig
- **Ursache**: Vorgabe erfordert `src/` als Top-Level, Python bevorzugt Package-Namen
- **Lösung**: `src/` beibehalten, aber mit `pip install -e .` als editable package
- **Lessons Learned**: Struktur-Vorgaben haben Vorrang, Development-Experience über pyproject.toml anpassen
